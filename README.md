# ClassHub · Presentación del proyecto de grado (SENA)

Presentación web con dos vistas sincronizadas.

- **`index.html`**: la vista del presentador. Tiene el guion, el repaso, las analogías, enlaces al código, las preguntas, un cronómetro y el asistente de IA.
- **`publico.html`**: la vista del proyector. Poco texto, letra grande y animaciones.

**Equipo:** Jerónimo Uribe Garcés, Juan Sebastián Carmona, Juan Diego Gaviria y Miguel Ángel Valencia.

## Cómo usarla
1. Doble clic en `ABRIR PRESENTACION.bat`. Levanta el servidor local con el asistente de IA y abre la vista del presentador.
2. Botón **Proyectar**: abre la ventana del público. Arrástrala al proyector y haz un clic dentro para ponerla en pantalla completa.
3. Para pasar de diapositiva: **→ / ←**, la barra espaciadora o un clicker.
   - **B** pone la pantalla en negro.
   - **/** abre el asistente.

La versión publicada en GitHub Pages funciona igual, pero sin el asistente de IA, que solo corre en el portátil. La clave de la IA nunca está en este repositorio.
